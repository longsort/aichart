# Design QA Checklist

## First impression
- Primary purpose is clear within 3 seconds.
- Main CTA is obvious.
- Screen is not visually noisy.

## Hierarchy
- Page title, section title, and content levels are distinct.
- Important information appears before secondary details.
- Cards and sections have clear grouping.

## Spacing and layout
- Uses consistent 4/8px spacing rhythm.
- Mobile has no horizontal scrolling.
- Desktop does not stretch content too wide.
- Touch targets are large enough.

## States
- Loading state exists.
- Empty state explains what to do next.
- Error state is recoverable.
- Success state confirms completion.
- Disabled state explains unavailable actions when needed.

## Accessibility
- Text contrast is readable.
- Forms have labels.
- Buttons are keyboard reachable.
- Focus states are visible.
- Icons are not the only source of meaning.

## Code quality
- Components are reusable.
- Props are clear.
- No broken imports.
- No dead buttons.
- No random one-off styles.

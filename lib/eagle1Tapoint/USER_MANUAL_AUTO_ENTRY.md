# 독수리1호 타점 · 코인별 자동진입 설명서

사용자용 가이드입니다. **확정 승률·확정 수익이 아닙니다.**  
게이지(점수)만 높아도 주문하지 않습니다.

---

## 한 줄 요약

**코인칩 ON + ARM(실전/가상) + 해당 코인 `확정롱/확정숏` + 필수게이트 통과 + 스윕합류 + 실시간 활동 합류**  
→ 그때만 그 코인에 **롱 또는 숏** 자동진입합니다.

- 동시에 같은 방향 확정이 **너무 많으면**(상관 클러스터) 일부는 막힐 수 있습니다.

## 어떤 신호일 때 진입하나?

### 1) 반드시 `확정롱` 또는 `확정숏`

| 화면 표시 | 의미 | 자동주문 |
|-----------|------|----------|
| **롱진입 / 숏진입 · AUTO** | 확정 + 게이트 + 스윕합류 + 활동합류 완료 | **예** |
| 확정롱 / 확정숏 · 스캔 | 확정이지만 게이트·스윕·합류 등 미충족 | 아니오 |
| 무장롱 / 무장숏 | 셋업만 준비됨 | **아니오** |
| 대기 | 방향·품질 미달 | 아니오 |

**무장(ARMED) ≠ 주문.** 타점·게이트·활동이 더 맞아야 `확정`이 됩니다.

### 2) 필수게이트 통과

대표적으로 막히는 경우:

- 전투존 없음 / 약한 단일존 (`WEAK_SINGLE`)
- 가격이 존에 없음
- 진입·위치 점수 너무 낮음
- 선진거래량이 방향과 반대
- 수수료·슬리피지 반영 **순기대값(NET EV)** 부족
- 흐름(FLOW)이 방향과 반대
- 데이터 품질·실행선(진입/SL) 불량

게이트가 막히면 카드에 `게이트 · …` 사유가 뜹니다.

### 3) 스윕합류 (필수 · 새 신호)

차트에 SWEEP 마커만 있어도 **주문하지 않습니다.**  
자동진입에는 **「스윕합류」** 카드가 발화되어야 합니다.

| SWEEP | 합류 방향 | 진입 |
|-------|-----------|------|
| 아래 털기(SSL) → 회수 | **확정롱**과 같으면 | **롱** 후보 |
| 위쪽 털기(BSL) → 거절 | **확정숏**과 같으면 | **숏** 후보 |
| **연속 2봉** 스윕(위·아래) + 라이브 롱/숏 | 같은 방향 | **합류 강화** |
| SWEEP만 / 방향 불일치 / 너무 오래된 차트 스윕 | — | **대기** (`스윕합류부족`) |

최근 **약 24봉** 안 SWEEP · **연속 2봉**이면 더 강하게 발화합니다.  
차트에만 보이는 예전 스윕(수십 봉 전)은 합류에 안 씁니다.

### 3-1) 캔들·RSI·선진 (합류 신호)

신호감지 라이브 **「캔들·RSI·선진」** 카드가 롱/숏 힌트를 줍니다.  
**단독 진입은 하지 않습니다.** 확정 + 스윕합류와 함께 합류 점수로만 씁니다.

### 4) 실시간 활동 합류

확정·스윕만으로 끝내지 않고, **실시간 활동 카드**에서 같은 방향(롱↔롱 / 숏↔숏)이고 강도 **55 이상**인 활동이 **1개 이상** 있어야 합니다.

합류에 쓰이는 활동 예:

- 스윕합류 (필수 · 위 3항)
- 볼륨폭발(5/15)
- 선진거래량
- 일봉면
- 이벤트
- 흐름·셋업
- 필수게이트 상태 등

예외: 진입 점수 **70 이상**이면 (스윕합류는 여전히 필수) 다른 활동 합류 0개여도 통과할 수 있습니다.  
그래도 **확정 + 게이트 + 스윕합류 + 진입선**은 필수입니다.

### 5) 진입선(가격) 있음

신호 ID · 진입가 · 손절가(SL)가 있어야 주문합니다. 없으면 `진입선 부족`.

## 스위치 (사용자가 켜는 것)

| 스위치 | 역할 |
|--------|------|
| **코인 칩 ON/OFF** | 그 코인만 허용/차단 |
| **자동매매 ON** | 자동실행 허용 |
| **타점 ARM ON** | 실전 주문 허용 (끄면 실주문 안 함) |
| **가상매매** | ARM 없이 가상 세션으로만 연습 |

ARM이 꺼져 있으면 `확정 · ARM ON 필요`처럼 대기합니다.

---

## 진입에 안 쓰는 것 (오해 방지)

- **점수 게이지만 높은 상태** → 주문 안 함  
- **무장(ARMED)만** → 주문 안 함  
- Scalp / Sniper / SFP / Breakout **이름만** → 롱·숏을 직접 결정하지 않음  
  → 이들은 확정·주문형태(시장가/지정가)를 **돕는** 엔진입니다.  
  **롱/숏은 `확정롱`/`확정숏` 방향**으로만 나뉩니다.

## 화면에서 보는 법

**신호감지 · 라이브 → 실시간 활동**

1. 위쪽 코인 버튼: `롱진입`/`숏진입` + `AUTO` 이면 그 코인 자동진입 조건 충족  
2. `스캔` = 아직 대기·무장·게이트/합류 부족  
3. `OFF` = 칩 꺼짐  
4. 아래 카드 **「코인별자동」** 줄에 사유가 한글로 나옵니다.  
   예: `롱 자동진입 · 스윕합류+활동 2` / `스윕합류부족 · …` / `실시간활동 합류부족` / `무장 · 타점대기`
5. **「스윕합류」** 카드가 초록/빨강으로 발화했는지 확인합니다.

「진입설명」 버튼을 누르면 화면에서도 이 요약이 펼쳐집니다.

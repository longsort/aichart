# 구조 판독 → 체결 (지정가 / 시장가)

맹목 시장가 진입을 하지 않는다.

## 원칙
1. **구조 먼저** (스윕회수 · BOS · 압축/확장 · VWAP이탈 · 거래량)
2. **체결은 구조에 맞게**
   - `LIMIT_MAKER` — 되돌림/회귀/스윕 → 지정가 대기 (메이커)
   - `LIMIT_JOIN` — 돌파 애매 → 스프레드 안쪽 지정가
   - `MARKET_TAKER` — BOS+거래량 확정 → 빠른 테이커만 허용
   - `WAIT` — 압축·무방향 → 진입 금지
3. 미체결 지정가는 `timeoutBars` 후 취소
4. 실주문은 별도 arm · 기본 페이퍼

## 코드
- `src/structure_execution.py` — 판독·플랜
- `src/live_signal_engine.py` — 신호 JSON에 `execution` 포함
- `GET /api/btc-edge/signal` — `execution` / `execModeKo`
